# Sunscoured South reference boundary

The Sunscoured South presentation reviewed the public
[Desert Dusky demonstration](https://desert-dusky.vercel.app) on 2026-07-29
as a read-only visual reference. Its public source and reuse license were not
established, so Warpkeep treats it as proprietary.

Only broad art-direction lessons were retained: a gradual warm transition,
layered sand tones, sparse vegetation, and clear silhouettes. No source,
shader, asset, texture, preset, screenshot, media, or dependency was copied.
Warpkeep's implementation was authored independently from deterministic realm
coordinates inside the existing terrain and ecology systems.

Private QA captures may compare the result with those general principles, but
the reference itself is not part of Warpkeep's runtime or release media.
