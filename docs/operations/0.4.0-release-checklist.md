integration and compiler-input ancestry:

1. Publish the reviewed source repair and derive its deployment closure from
   canonical Git blobs. Pass the required checks and merge this source-only M1.
2. Verify the actual signed M1 merge and reviewed tree. Prepare and independently

3. Integrate that authenticated family in a generated-only M2 through normal
   protections. Preserve its M1 source identity; do not relabel a development
   candidate whose input is absent from main ancestry after squash.
4. Wait for M2's exact push-to-main Verify to succeed, recheck live main, and then
   run preflight. Do not dispatch protected operations against interim M1, where
   the operation bundles still describe the previous source graph.
