THE PRODUCT WE ARE FINISHING

A real person, a permanent keep, and a world worth returning to.

Make gather -> choose -> build -> benefit -> return understandable, rewarding
and dependable. The shared atlas supplies journeys; the keep turns their returns
into visible improvements. The first economy building AND its improved credited
return must fit within ten minutes on actual atlas routes in the owner's PTR.

The Verdant Citadel should feel like one intentional place: pale masonry, dark
timber, teal roofs, warm activity, layered forest, restrained warp accents.
Voxel scenery and water mainly support presentation. Professional means coherent,
readable and responsive on a phone, not more effects or a larger simulation.
