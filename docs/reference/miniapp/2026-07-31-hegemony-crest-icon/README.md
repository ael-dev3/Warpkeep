# Hegemony crest icon

On 31 July 2026, the Warpkeep project owner supplied the source image in this
directory and instructed that it be used as Warpkeep's Mini App icon and
website favicon. That instruction authorizes use in this repository and the
official `warpkeep.com` presentation; it does not independently establish
copyright ownership or grant a general open-content license.

The source is a 1254×1254 opaque RGB PNG, 2,297,825 bytes, with SHA-256
`d826fefc276f61490f152293aa80f0c266e9d986760e956eeb7837d00e0affe8`.
`scripts/prepare-farcaster-miniapp-assets.mjs` verifies that exact input and
uses deterministic Lanczos3 resizing plus a 256-color opaque PNG encoding to
produce the Mini App, favicon, and Apple touch-icon derivatives.

The artwork contains no profile image, FID, wallet address, QR payload,
authentication proof, token, credential, private log, or player state. The
source and derivatives remain `LicenseRef-Warpkeep-Provenance-Required`; see
[`../../../../ASSETS-LICENSE.md`](../../../../ASSETS-LICENSE.md).
